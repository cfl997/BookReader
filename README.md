# 书籍读器离线版

一款基于 Qt 开发的离线 TXT 文本阅读器，支持自动滚动朗读、快捷键操作、书签索引等功能，适用于长时间阅读小说或电子书。

## 主要功能

### 阅读模式

- **全文模式（Full Mode）**：完整窗口阅读，支持滚动条、翻页、逐行浏览，可配置字体、颜色、行间距等显示参数。
- **单行模式（One Line Mode）**：无边框、置顶的极简单行显示，只展示当前一行文字，适合配合其他应用使用。

### 自动滚动

- 可调节的自动滚动速度（1-150 档），左右方向键实时微调。
- 智能断行：自动在标点符号处停顿，阅读体验更流畅。
- 支持记忆阅读位置，重新打开文件自动跳转到上次位置。

### 语音朗读

- 内置文本转语音（TTS）朗读功能，按下快捷键开始朗读。
- 支持音量、语速、音调调节，可选择不同的语音引擎。
- 在标点符号处自动暂停朗读，朗读结束后自动停止。

### 快捷键

| 功能 | 快捷键 |
|------|--------|
| 朗读开关 | `Ctrl+F12` |
| 显示/隐藏窗口 | `Ctrl+Shift+T` |
| 自动滚动开关 | `Enter` / `Return` |
| 上一行/下一行 | `↑` / `↓` |
| 上一页/下一页 | `PageUp` / `PageDown` |
| 滚屏速度调节 | `←` / `→`（自动滚动时） |

### 文件与编码

- 支持打开 `.txt` 文本文件，自动检测编码（支持 GBK、UTF-8 等常见编码）。
- 手动切换编码：菜单栏 -> 编码，随时调整。
- 维护最近打开文件列表，方便快速访问。
- 定时自动保存阅读进度（每 5 分钟），程序关闭时也会保存。

### 书签与索引

- **索引功能**：自动扫描章节标题（支持自定义正则表达式），生成可跳转的章节列表。
- **高级索引**：支持自定义正则表达式匹配章节标题。
- **搜索功能**：在全文中搜索关键词，高亮显示匹配结果并快速定位。

### 系统托盘

- 单行模式下可最小化到系统托盘。
- 托盘图标右键菜单：显示/隐藏窗口、朗读控制、设置菜单、退出程序。
- 双击托盘图标快速显示窗口。

### 显示配置

- 全文模式和单行模式分别独立配置：
  - 字体（大小、粗细、斜体、样式）
  - 前景色（文字颜色）与背景色
  - 行间距
  - 内边距
  - 智能断行开关

## 系统要求

- Windows/Linux/macOS（跨平台支持）
- Qt 5.x 或更高版本

## 编译

```bash
# Windows (使用 Qt Creator 或 qmake)
qmake bookreader.pro
make

# Linux/macOS
qmake bookreader.pro
make
```
